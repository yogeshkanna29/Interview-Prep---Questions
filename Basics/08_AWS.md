# AWS basics Important Interview Notes

1. What is AWS?

- AWS (Amazon Web Services) is a cloud computing platform that provides services like computing, storage, databases, networking, and security.

2. EC2

- EC2 (Elastic Compute Cloud) is a virtual server in AWS used to host applications.

Use Case:
- Host a Node.js application.

3. S3

- S3 (Simple Storage Service) is an object storage service used to store files like images, videos, backups, and documents.

Use Case:
- Store profile pictures or uploaded files.

4. RDS

- RDS (Relational Database Service) is a managed database service that supports MySQL, PostgreSQL, SQL Server, etc.

5. Lambda

- AWS Lambda lets you run code without managing servers. You pay only when your code runs.

6. IAM

- IAM (Identity and Access Management) is used to manage users, roles, and permissions in AWS.

7. CloudWatch

- CloudWatch is used to monitor applications, servers, logs, and performance metrics.

8. Elastic Beanstalk

- Elastic Beanstalk is a service that automatically deploys and manages web applications.

9. API Gateway

- API Gateway creates and manages REST APIs and routes requests to backend services like Lambda.

10. VPC

- A VPC (Virtual Private Cloud) is a private network inside AWS where you can securely run your resources.
